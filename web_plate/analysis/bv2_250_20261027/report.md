# Bv2 seed42 / seed123：250轮结果分析

检查日期：2026-10-27。只读分析实验记录，未修改代码、配置、载荷或运行数据，未重新训练、调用 LLM 或执行 FE。

## 主要结论

1. **完整框架在 seed42 的版本对齐比较中仍取得最好结果。**Bv2 最终 FE 目标值1.105069，比固定架构 A 高3.36%，比关闭继承保护的 C 高6.19%，比随机提案 D 高5.19%；过程最优值均值也分别高3.15%、4.70%、2.08%。这支持完整方案在当前问题和这一次配对运行中有效。
2. **seed123 的 Bv2 最终结果接近 seed42。**最终值1.111823，比 Bv2 seed42 高0.61%；但到达1.00的轮数为27和51，优化过程仍明显依赖随机轨迹。两个种子不足以证明稳定性，而且没有 A/C/D seed123，不能作跨种子配对优势结论。
3. **继承保护和 v2 范围约束均确实执行。**Bv2 seed42 审查30次、继承7次；seed123 审查27次、继承4次。两组分别有5次、4次原始规则本会接受的候选被新增排序增益门槛挡住。
4. **仍未证明评价指标与真正优化收益完全一致。**Bv2 seed42 的批次平均排序准确率低于 C/D，但 FE 最终值更高；一些后期继承没有可见阶段最优值收益。不能根据排序指标或继承次数，直接断言优化收益的来源。

## 实验完整性与预算

- Bv2 seed42 和 seed123 均完整记录1至250轮，state.next_iteration 都为251。
- 每组原始样本300个，新增 FE 尝试5000次，总样本预算5300；不是相同训练计算量。
- 两组初始文件 SHA256 都为 `2a5ce46e786cf74fe492b32cad34593457e0f32c98f02a60eef038a09fb98d4f`，与 A/C/D 相同。
- 核对逐轮 manifest 样本数，以及 fe_request / fe_result 有效输入输出在 dataset_0251.mat 中的追加内容，未发现链路错误；初始300个样本也精确保留。最终数据最大值与记录一致。
- seed42 有4999个新增有效 FE 结果、1个失败，最终5299个有效样本；seed123 有4995个有效结果、5个失败，最终5295个有效样本。失败项没有混入追加的有效数据。
- 两组记录的请求最大覆盖率均为0.299795，未超过0.30。这里核对的是 FE 请求中记录的覆盖率，并非额外重新验证 COMSOL 几何。
- 两组所有审查 trace 均为 proposal_scope_v2，继承保护开启，审查间隔均不少于5轮；模型/地址记录为 gpt-5.6-sol / https://www.onetopai.com/v1。
- Bv2 seed42 与 C 的配置差别仅为实验名和 inheritance.enabled；与 D 的差别仅为实验名和 proposal_source；与 Bv2 seed123 的差别仅为实验名和 random_seed。比较时将旧快照未显式存储的 proposal_source 解释为默认 llm。
- 起跑前 provenance 中48个文件（源码、MATLAB入口、初始数据、COMSOL文件及两份配置）与当前哈希全部一致。这证明两个时点的文件一致，不能排除运行期间临时修改后恢复或远程模型服务变化。

断网/内存中断后，未完成轮重新执行可能重复 LLM 调用和训练，提案也可能变化。本次结果描述的是实际完成的含恢复过程运行，并非理想无中断运行的精确复现。

## 机制执行证据

| 指标 | Bv2 seed42 | Bv2 seed123 |
|---|---:|---:|
| 架构审查 | 30 | 27 |
| 继承新架构 | 7 | 4 |
| 临时不同候选被回退 | 16 | 15 |
| 没有不同临时赢家 | 7 | 8 |
| 新增保护独立改变原始接受决定 | 5 | 4 |
| 接受候选不足5个的审查 | 0 | 1 |

seed42 的继承轮为5、10、20、59、93、115、173；seed123 为50、83、208、241。所有继承都通过配置中的原始排序规则、pairwise 改善至少0.03和 top-k regret 增加不超过0.02等检查。

seed42 第41、46、140、195、206轮的原始规则本会接受候选，但 pairwise 改善分别仅0.01579、0.02105、0.00526、0.00526、0.00526，因此被新增保护拒绝。seed123 对应61、94、175、186轮。这证明排序增益门槛实际影响了决策，不证明每次拒绝都提高后续最优值。

两组记录中虽然 top-k 退化条款分别出现6、4次，但这些案例也已被原始规则否决或同时不满足其他条件；**本次 Bv2 没有 top-k 条款单独改变原始接受决定的案例。**C 关闭的是整个保护，现有消融也不能区分排序增益门槛和 top-k 保护各自贡献。

v2 trace 不再出现旧 B 的 `supporting_field_not_editable: name`。仍存在部分“提案值没有落实到实现”或“配套变化声明不正确”的拒绝，这与约束预期一致；不能把所有候选拒绝都当成框架故障。

## 不能忽略的现象

**批次预测指标与优化效果仍脱节。**A / Bv2 seed42 / C / D 的平均 pairwise 为0.6605 / 0.6183 / 0.6688 / 0.7589；对应平均 top-k regret 为0.1504 / 0.1677 / 0.0937 / 0.0812。Bv2 seed42 这两项甚至不如 A，却取得更高 FE 最优值。

这并不自动说明排序没有用，而是各组评价的样本由自己的搜索策略选择，难度、分布、集中程度都不同。这些均值不能用于跨组证明模型泛化能力。对实际优化的判断，应以真实 FE 最优值和样本效率为主。

**继承更多或后期通过门槛，不等于一定增加搜索收益。**seed123 第208轮继承后到下次审查前，最好值没有提高；第241轮继承后到250轮也没有提高。seed42 第59、173轮继承后的相应阶段增益也很小。阶段比较没有“保留父架构”的反事实，因此这些现象提示收益递减，不足以证明替换有害。

**审查和继承需要区分。**审查轮的候选 FE 批次由临时赢家参与生成，随后才决定是否继承。即使被回退，临时候选仍可能改变已经加入的数据。因此 B 对 C/D 的整体差异不能全部归因于最终继承的几个架构。

两组不确定度与误差的平均相关仅约-0.0028、0.0054，实际选中 FE 批次上没有明显的误差识别关系。MC dropout / UCB 是否有效仍需专门检查；本次不能确认它是收益来源，也不能凭这些选择后样本否定整个设计空间上的能力。

## 对下一步实验的判断

现在可以把 A42 / Bv2-42 / C42 / D42 作为版本对齐的初步消融结果，把 Bv2-123 单列为第二次运行结果。不要把250轮当作250次独立重复，也不要把 Bv2-123 与 A42 的差异称为同种子验证。

若下一步主要想确认完整框架的优势是否跨种子成立，优先补 A seed123，形成第二个 A/B 配对；若要确认保护和 LLM 的消融差异也稳定，再补 C/D seed123，并增加事先选定的更多共同种子。当前不建议仅依据这一轮结果继续调整门槛；应先冻结版本、预算和主要评价终点。
