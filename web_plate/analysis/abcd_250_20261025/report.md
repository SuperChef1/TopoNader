# Seed 42：A/B/C/D 前250轮实验检查

检查日期：2026-10-25。仅分析已有记录，没有重新调用 LLM、训练或 FE，也没有修改实验配置和数据。

## 结论

最终最优真实 FE 目标值为 **B > A > D > C**。完整 TopoNader B 比固定架构 A 高4.36%，比取消继承保护的 C 高7.22%，比随机提案 D 高6.21%。这一组结果与“LLM 提案和继承保护有帮助”的假设一致，但**尚不能证明这两个模块的独立因果收益，更不能证明跨随机种子稳定有效**：旧 B 使用 proposal_scope_v1，C/D 使用修正后的 v2，而且目前每组只有 seed 42 一次运行。

C/D 的消融开关确实生效，数据链没有发现断裂。没有发现能直接解释结果差异的续跑错位或错误拼接。

A 训练检查点数250。检查点数包含候选训练，是计算开销的粗略代理，不能据此直接推算 GPU 小时。

**C：关闭保护有效。**27次审查均按原始 FE 字典序规则决策，未发现 enabled=true 或决策与原始规则不一致。6次继承发生于5、16、39、61、137、181轮。其中4次若把现有保护门槛静态应用在当时的同一对父子指标上，会被拒绝：

| 轮数 | pairwise 改善 | top-k regret 增加 | 现有保护的拒绝原因 |
|---|---:|---:|---|
| 5 | +0.04737 | +0.03543 | regret 增加超过0.02 |
| 16 | +0.08187 | +0.07948 | regret 增加超过0.02 |
| 61 | 0 | -0.03625 | 排序改善不足0.03 |
| 181 | +0.02105 | 0 | 排序改善不足0.03 |

这说明保护能改变实际决策；不等于证明这4次替换造成 C 最终落后。例如5、16轮后仍取得了明显阶段收益；61轮虽然 pairwise 不变，但 top-k regret 改善。若当时拒绝继承，后续采样、数据、训练和 LLM 提案都会变化，无法从当前日志恢复那条反事实轨迹。

**D：随机路线有效。**26次 trace 均记为 random，未发现 LLM usage、agents 调用记录或 post_reflection。候选尝试涵盖宽度、深度、编码器、潜变量、激活、归一化、dropout、预测器8类操作；每次审查均收集到5个接受候选。4次继承发生于37、57、212、234轮，审查间隔均不少于5轮。

D 第64轮是 top-k 保护独立改变原始决策的具体例子：pairwise 改善0.03158，达到0.03要求，但 regret 增加0.04413，超过0.02，因此拒绝。第26轮同时未通过两项门槛；80、124、146、223轮则因排序增益不足被拒绝。这里同样只能证明保护确实执行，不能证明拒绝后一定比接受更优。

## 当前暴露出的评价与搜索脱节

| 每轮 FE 批次指标均值 | A | B | C | D |
|---|---:|---:|---:|---:|
| pairwise accuracy，越高越好 | 0.6605 | 0.6777 | 0.6688 | **0.7589** |
| top-k regret，越低越好 | 0.1504 | 0.1234 | 0.0937 | **0.0812** |

D 在这些局部批次预测指标上最好，最终结构目标值却不如 A/B；C 的 regret 也好于 B，但最终优化更差。不能用这些均值代替最终 FE 优化效果。各组评价的是自己提出的不同 FE 批次，而非共同、同分布测试集；模型可能在自己集中采样的局部区域排序很好，却没有发现更高值区域。因此“排序指标好看，但探索收益不足”是与记录相容的解释，尚未被单独验证。

另外，审查轮的 FE 候选在最终继承决策之前，由临时胜出的模型参与生成。回退只决定后续继承架构，不能撤销已经投入 FE 的当轮候选和新增数据；不能把“拒绝子架构”理解成“本轮搜索没有受到它影响”。

现有不确定度与绝对误差的平均 Spearman 相关约为 A 0.064、B 0.026、C 0.061、D 0.056，均较弱。这提示 MC dropout 不确定度在实际被选 FE 批次上的误差识别能力有限，可能约束 UCB 探索效果；它不是经验证的根因，也不能由这些选择后样本推广到整个设计空间。

## 成本和结论边界

- C 有468次记录调用，输入3,484,857 token、输出334,635 token，记录调用耗时相加约4.98小时。B 对应461次、3,159,200 / 282,632 token、约3.78小时。这里不是完整实验墙钟时间，也不是实际账单；不能估算出精确费用。
- D 无 LLM 费用，但仍有406个训练检查点，因此随机架构搜索也不是固定架构训练成本。
- B 的 v1 曾因 cosmetic name 声明误拒候选，C/D 已使用 v2。这个差异不能假定对结果方向有利或有害。
- 相同42种子不保证相同闭环轨迹：候选、架构、数据或审查时间改变后，后续优化会分叉；也不能把多轮自相关记录当作250次独立重复进行显著性检验。
- D 对比的是当前定义的随机局部变异分布；它替换了整个 LLM 候选生成及反思流程，不能单独归因为 LLM 某一个角色，也不代表所有随机 NAS 方法。
- 当前没有四组互相匹配的不可变 COMSOL 二进制/载荷快照证据。本报告确认的是初始数据、运行配置和 FE 数据链一致性，不能独立追溯证明历史物理模型从未变化。
